# Fundamentos de Ciencia de Datos
##  Descripción general del proyecto
El objetivo de este proyecto es analizar la relación entre el consumo eléctrico y las variables climáticas (temperatura, humedad y velocidad del viento), así como los factores temporales (hora y día), con el fin de identificar patrones de comportamiento energético y posibles factores que influyen significativamente en la demanda eléctrica de la ciudad de Tetuán, Marruecos.

## Conclusiones halladas
El análisis exploratorio del clima en Tetuán permitió identificar patrones coherentes entre las variables meteorológicas, evidenciando relaciones esperadas como la correlación inversa entre temperatura y humedad. Aunque se detectaron algunos valores atípicos, principalmente en temperatura y consumo energético, estos parecen deberse a variaciones naturales del clima más que a errores de medición, por lo que se mantendrán para conservar la representatividad de los datos.
